# 🌌 Professional Portfolio - Dn Mohanty

A modern, high-performance personal portfolio website built with a focus on **AI & ML Engineering**. This project showcases a blend of creative design, interactive elements, and robust frontend development practices.

![Portfolio Preview](public/photo/portfolio.png)

---

## 🚀 Key Features

- **🌓 Dynamic Theming**: Seamlessly switch between Light and Dark modes with automatic persistence using `localStorage`.
- **✨ Interactive Background**: A stunning particle system powered by `Particles.js` that responds to mouse movement and clicks.
- **⌨️ Animated Typing**: A custom-built typing effect for the hero section with multi-line support and particle trails.
- **📊 Animated Skill Bars**: Intersection Observer-driven progress animations that trigger when skills come into view.
- **📱 Fully Responsive**: Optimized for all devices, from ultra-wide monitors to mobile screens.
- **📧 Contact Integration**: Functional contact form powered by **Formspree** with AJAX submission and visual feedback.
- **🛡️ Dev-Sec Measures**: Custom scripts to disable right-click and common "Inspect Element" shortcuts to protect intellectual property.
- **🎨 Modern UI**: Features glassmorphism, smooth gradients, and scroll-triggered reveal animations.
